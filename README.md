# 시험지 HWP 변환기

시험지 PDF를 HWP 서식으로 바꾸는 웹 도구입니다.
https://hayerin.github.io/hwp-converter/

- 문항, &lt;보 기&gt;·&lt;조 건&gt; 박스, 지문, 표, 그림, 밑줄을 그대로 옮깁니다.
- 정답·해설은 문항마다 미주로 넣습니다(` [정답] … [해설] …`).
- 그림은 PDF 안의 원본 이미지를 그대로 넣습니다.
- 만든 HWP의 글자를 PDF 본문과 한 글자씩 대조해 결과를 보여 줍니다.
- 모든 처리는 브라우저 안에서 이루어지며, PDF는 서버로 올라가지 않습니다.

## 사용 방법

1. 사이트를 열고 PDF 파일을 끌어다 놓습니다(여러 개 가능).
2. 밑줄 친 글이 줄 끝에서 다음 줄로 넘어가는 곳은 PDF에 띄어쓰기 정보가 없습니다. 「확인할 곳 보기」에서 PDF 조각을 보고 붙여 쓰기/띄어 쓰기를 고릅니다.
3. [HWP 만들기]를 누른 뒤 파일별 [HWP 저장] 또는 [모두 ZIP으로 저장]으로 받습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 배포용 페이지 (`node build.mjs`로 생성) |
| `src/app.html` | 화면과 동작 |
| `src/hwpconv.js` | PDF 분석과 HWP 생성 |
| `src/data.js` | 4-1 서식 템플릿(글자 내용 제거), 글자 폭, 띄어쓰기 판정 기본값 |

`src/`를 고친 뒤 `node build.mjs`를 실행하면 `index.html`이 다시 만들어집니다.

## 제한

- 정해진 시험지 양식에 맞춘 도구입니다. 다른 양식의 PDF는 인식이 틀릴 수 있습니다.
- 보호가 해제된 PDF만 읽을 수 있습니다.
- 한글 프로그램에서 처음 열 때 줄 나눔을 다시 계산합니다. 줄 간격이 어색한 문단은 글자 하나를 고치면 바로 정리됩니다.
